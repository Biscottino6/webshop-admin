# IT-Notdienst BW

Starter-Projektstruktur für einen IT-Notdienst-Shop mit Kundenbereich, Adminpanel und API.

## Setup
1. Projekt in Webroot legen.
2. Datenbank via `database/schema.sql` importieren.
3. Optional Testdaten via `database/seed.sql` importieren.
4. `config/database.php` anpassen.

## Einstieg
- Frontend: `index.php`
- Admin: `admin/login.php`
- API: `api/status.php`
